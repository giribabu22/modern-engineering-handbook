# 12 — Engineering Leadership

> *The best engineers don't just write good code — they make everyone around them better.*

This section covers the non-technical skills that separate great engineers from good ones: technical decision-making, communication, mentorship, project estimation, and navigating organizational complexity. These skills grow more valuable as AI takes over more routine implementation work.

## Key Ideas

- **Technical decisions are people decisions**: The best technical choice is worthless if the team can't execute it.
- **Writing is thinking**: A good design document forces clarity before any code is written — and a clear specification is also what makes AI assistants effective.
- **Leadership is a choice, not a title**: You can lead from any position on the team.
- **Review is the new bottleneck** *(AI era)*: When code is cheap to produce, the team's capacity to review and verify it sets the pace. Keep changes small and automation strong.
- **Measure outcomes, not output** *(AI era)*: Lines of code and PR counts go up with AI; lead time, change failure rate, and escaped defects tell you whether things actually improved.
- **Protect the learning curve** *(AI era)*: Junior engineers still need the struggle that builds judgment. Mentor them to use AI as a tutor, not just a generator.

## Prerequisites

At least some professional engineering experience recommended.
