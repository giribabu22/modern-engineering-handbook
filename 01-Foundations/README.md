# 01 — Foundations

> *Before you write code, you must learn how to think.*

This section establishes the mindset, problem-solving frameworks, and foundational knowledge that every software engineer needs — regardless of language, stack, or specialty. In an era where AI can produce code on demand, these skills are what let you judge whether that code solves the right problem, correctly.

## Key Ideas

- **Abstraction**: The most powerful tool in software. Hiding complexity behind clean interfaces.
- **Decomposition**: Breaking big problems into smaller, solvable ones.
- **Iteration**: Software is never finished. It evolves.
- **Tradeoffs**: Every decision is a compromise. There is no "best" — only "best for this context."
- **Verification over generation** *(AI era)*: When answers are cheap, the ability to check them — through reasoning, experiments, and tests — is the scarce skill.
