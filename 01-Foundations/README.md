## Key Ideas

- **Abstraction**: The most powerful tool in software. Hiding complexity behind clean interfaces.
- **Decomposition**: Breaking big problems into smaller, solvable ones.
- **Iteration**: Software is never finished. It evolves.
- **Tradeoffs**: Every decision is a compromise. There is no "best" — only "best for this context."
